# Step 6: glTF import, frustum culling, and profiling

Static glTF/GLB loading preserves shared geometry, node transforms, base-color textures/materials,
UV transforms, sampler settings, and unlit/alpha-mask flags. Rendering uses camera frustum culling.
The benchmark CLI reports CPU recording and optional per-frame GPU timestamps. See README.md
for commands, supported features, limitations, and measured results.
